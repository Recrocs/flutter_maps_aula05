# Flutter Maps - Aula 05

Projeto da Aula 05 de PPDM2 usando Flutter Map e OpenStreetMap.

## Funcionalidades

- Exibe o mapa.
- Permite clicar em um ponto.
- Obtém latitude e longitude.
- Mostra um marcador no ponto clicado.

## Teste

```bash
flutter pub get
flutter run -d chrome
```

Também pode ser testado em um emulador Android.

## APK

```bash
flutter build apk
```

Coloque o APK em `assets/flutter_maps.apk`.

Coloque o print solicitado em `assets/print-flutter-maps.png`.
